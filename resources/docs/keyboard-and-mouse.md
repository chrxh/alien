# Keyboard and mouse

A compact list of all mouse actions and keyboard shortcuts. Shortcuts do not work while a text field has the keyboard focus.

## Mouse

| Action | Navigation mode | Edit mode |
| --- | --- | --- |
| Mouse wheel | Zoom | Zoom |
| Middle mouse button and drag | Move the view | Move the view |
| Left mouse button | Hold to zoom in | Use the selected tool, for example select, draw or push |
| Right mouse button | Hold to zoom out | With the selection tool: drag a selection rectangle. With line, curve and polygon tools: remove the last point |
| Ctrl and left click | | Add an object to the selection or remove it |
| Shift while moving | | Switch temporarily between moving selected objects and entire networks |

## General

| Shortcut | Function |
| --- | --- |
| F1 | Open or close the documentation |
| F7 | Switch between full screen and window |
| Space | Run or pause the simulation |
| Ctrl+N | New simulation |
| Ctrl+O | Open simulation |
| Ctrl+S | Save simulation |

## Editing

| Shortcut | Function |
| --- | --- |
| Alt+E | Switch the edit mode on or off |
| Alt+N | Inspect the selected objects |
| Alt+F | Open the genomes of the selected creatures in the genome editor |
| Alt+P | Inspect the selected creatures |
| Esc | Close all inspection windows, or deselect |
| Ctrl+C | Copy the selection |
| Ctrl+V | Paste |
| Del | Delete the selection |
| Enter | Finish a line, curve or polygon |
| Esc | Abort a line, curve or polygon |

| Shortcut | Function |

| Alt+I | Show or hide the simulation |
