# Keyboard and mouse

This chapter lists the keyboard shortcuts and the main mouse actions. Shortcuts do not work while a text field has the keyboard focus or while a dialog is open.

## Mouse

| Action | Navigation mode | Edit mode |
| --- | --- | --- |
| Mouse wheel | Zoom | Zoom |
| Middle mouse button and drag | Move the view | Move the view |
| Left mouse button | Hold to zoom in | Use the selected tool, for example to select, draw or push objects |
| Right mouse button | Hold to zoom out | With the **Select and move** tool: drag a selection rectangle. With the line, curve and polygon tools: remove the last point |
| Ctrl and left click | | With the **Select and move** tool: add the objects under the cursor to the selection or remove them |
| Drag the round handle above the selection frame | | Rotate the selection |
| Hold Shift | | Switch temporarily between **Apply to selected objects** and **Apply to entire networks**. This affects edits such as moving, rotating, copying and deleting. |
| Drag the selection while the simulation runs | | Move the entire networks, even with **Apply to selected objects** or **Shift**. Releasing the mouse button while still moving the mouse throws them. |

Some windows have mouse actions of their own, for example:

- Hold **Ctrl** and click a slider to type in a precise value.
- Double-click an entry in the **Browser** to download and open it.
- Hold **Ctrl** and click rows in the lineage table of the **Evolution dashboard** to select several lineages.
- In the preview of the genome editor, turn the mouse wheel to zoom and drag with the middle mouse button to move the view.

## Editing

Apart from **Alt+E**, these shortcuts work only in edit mode.

| Shortcut | Function |
| --- | --- |
| Alt+E | Switch the edit mode on or off |
| Alt+N | Inspect the selected objects |
| Alt+F | Open the genomes of the selected creatures in the genome editor |
| Alt+P | Inspect the selected creatures |
| Esc | Close all inspection windows or, if none is open, clear the selection |
| Ctrl+C | Copy the selection |
| Ctrl+V | Paste |
| Del | Delete the selection |
| Enter | Finish a line, curve or polygon |
| Esc | Abort a line, curve or polygon |

## Network

**Alt+D** and **Alt+Q** work only while you are logged in.

| Shortcut | Function |
| --- | --- |
| Alt+L | Log in |
| Alt+D | Upload simulation |
| Alt+Q | Upload genome |
